# 2차 픽셀아트 리뉴얼 · 아트 작업 인계

공용 기준은 `f79c0e9`의 [1차 시안 기준표](renewal-slice-1-spec.md)와 [리뉴얼 기획안](pixel-art-renewal.md)이다. 실행 화면은 [renewal-slice.html](../public/renewal-slice.html)이다.

## 에셋과 조립 규칙

| 요소 | 구성과 동작 |
| --- | --- |
| 캐릭터 | 발 기준 32×40 작업 프레임과 32px 서 있는 키, 16px 머리 비례를 사용한다. 머리·헤드셋·손·재킷·바지·신발을 방향별로 합성한다. 6단계 보행은 이동 거리를 사용하고, 5단계 착석과 기립은 통로점과 좌판 사이를 오간다. 타이핑 손 4단계는 키보드 좌표를 사용한다. |
| 의자 | 바퀴·좌판과 등받이를 별도로 그린다. 마지막 두 착석 자세에서만 등받이를 캐릭터 앞에 그리므로 통로에 서 있는 동안 머리가 등받이에 가려지지 않는다. 기립은 순서를 역으로 적용한다. |
| PC와 책상 | 정면과 양쪽 측면용 상판·모니터 하우징·받침·본체·키 묶음·마우스·패드·쟁반을 분리했다. 모니터는 꺼짐·부팅·사용 화면을 구분한다. 배달 쟁반은 공용 앵커에 배치한다. |
| 시설 | 입구와 1인룸 문에 문턱·양쪽 문짝·레일·상인방을 적용한다. 상인방의 앞뒤는 문턱 기준으로 정렬한다. 키오스크는 본체·받침·리더기와 대기·선택·확정 화면을 갖는다. |
| 환경 | 극락조·포토스·다육은 각각 잎 실루엣, 줄기, 화분과 흙을 가진다. 마룻결, 천 러그 테두리, 창과 벽 하단, 외부 타일은 별도로 그린다. 바깥 통행 구간의 밝기는 기존 통행 데이터에서 가져온다. |

게임은 [renewal-slice-art.mjs](../public/renewal-slice-art.mjs)의 원본 픽셀 도형을 캔버스에 그려 각 요소를 조립한다. 받침·손·등받이·문턱의 월드 좌표와 상호작용 범위는 [공용 배치 모듈](../public/renewal-layout.mjs)에서 가져온다. 실내 건축의 팔레트, 나뭇결, 창틀 표현과 씬의 깊이 순서는 [renewal-slice.js](../public/renewal-slice.js)에 있다.

## 총괄 및 후속 작업자 확인 사항

- 공용 좌석 키, 충돌 박스, 통로 폭, 가구·문 치수 및 배치 데이터의 변경은 없다.
- **1인석 책상, 아트·배달.** 기준 시안의 우측 본체는 쟁반 앵커 상단에 겹쳤다. 시각 요소인 본체를 동일 상판 왼쪽으로 옮겼으며, 책상과 쟁반 좌표는 공용 데이터를 사용한다. 전체 룸 제작 시 쟁반과 PC 본체를 함께 배치해 확인한다.
- **1인석 타이핑, 배치·모션.** 키보드 중심 `(116,89)`은 좌판 `(124,108)`보다 왼쪽 8px이다. 현재 자세는 손을 왼쪽으로 뻗고 뒤쪽 손 일부를 머리 뒤에 가린다. 전체 룸에 같은 비대칭을 적용하기 전 손 접점과 오른쪽 마우스 패드 및 쟁반 간격을 함께 검토할 수 있다.
- **일반석, 배치·아트.** 공용 시안의 측면 모니터 외곽 `16×22`에 화면과 스탠드를 맞췄다. 정면 `26×19`와 방향 차이가 크므로 다른 룸에 측면 변형을 늘릴 때 같은 모델로 읽히는지 점검한다.
- **통합 검수.** 현재 시안은 입구·키오스크·일반석 두 자리·1인룸 범위다. 나머지 룸, 매점·휴식·테라스, 실제 배달 이동과 멀티플레이, 운영 페이지와 카메라 통합은 별도 검수가 필요하다. 브라우저에서 본 쟁반은 시안의 QA 토글로 표시했다.

## 검증 경로

- Chrome FHD `1920×1080`에서 방향키로 입구 통과 → 키오스크 클릭 → 좌석도에서 `hall:0` 선택·확정 → 착석·부팅·타이핑 → 1인석 클릭 → 기존 자리에서 기립 → 방 문 통과 → `solo:0` 착석·타이핑 → 기립점 `(124,132)` 복귀를 확인했다.
- Chrome 4K `3840×2160` 및 모션 감소에서 입구 → 키오스크 좌석도 → `hall:1` 착석·부팅·타이핑 → 기립점 `(526,144)` 복귀를 확인했다.
- 실제 캡처의 실내 영역에서 논리 픽셀 하나가 FHD `3×3`, 4K `6×6`의 동일 색상 블록인지 검사했다. 브라우저 JavaScript 오류는 없었다.
- 단위 테스트 36개와 프로덕션 빌드를 통과했다.
