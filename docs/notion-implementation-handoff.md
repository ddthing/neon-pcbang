# Notion 구현 인수인계

[Notion 원문](https://app.notion.com/p/16-16-4241906cddf181b791a1deedbce972d0)의 하단 배치·기능·검수 항목까지 기준으로 삼는다. 그중 3번 Downtown Eats를 인테리어, 7번 Free Pixel Art Foods를 진열·음식 픽셀 아트의 주 에셋으로 사용한다. 팩에 없는 PC, 키오스크, 자판기, 파티션, 창밖 스카이라인, 한식 메뉴는 프로젝트에서 제작한 16px 계열 PNG를 사용한다.

## 이어서 실행하기

1. `notion-pastel-art` 브랜치를 체크아웃한다.
2. [README의 에셋 설치 절차](../README.md#-1616-파스텔-픽셀아트-제작-지침)대로 공식 다운로드 3개를 풀고 `node scripts/install-notion-art.mjs <DowntownEats_FREE> <Weather_FX> <Food_Icons>`를 실행한다. 세 경로는 팩의 `catalog.json`, FX의 `overlays/`, 음식의 `soda_coke.png`가 각각 들어 있는 폴더다. 다운로드한 원본 팩은 저장소에 올리지 않는다. 에셋이 설치된 체크아웃을 사용해야 매장 캔버스를 볼 수 있다.
3. [README의 로컬 실행 절차](../README.md#로컬에서-실행하기)에 따라 빌드하고 로컬 D1 마이그레이션을 실행한다. 게시판에는 `drizzle/0010_cafe_board.sql`이 필요하다.
4. `node --test 'tests/*.test.mjs'`로 자동 테스트를 실행한다. 로컬 접속 후 Notion의 데스크톱·모바일 기준을 실측한다.

## 구현 및 확인

- `public/cafe-map.mjs`가 768×512 논리 월드와 41석 배치의 원본이다. 일반석 22, 1인석 4, 2인룸 두 곳에 4석, 5인룸 5, 6인룸 6이다. 기존 `hall:22` 이상에 대한 운영 데이터 정리 및 이전 동작은 배포 전에 확인한다.
- `public/cafe-art.js`, `public/pixel-tiles.js`에서 팩 3·7과 제작 에셋을 합성한다. 배치 변경은 `cafe-map.mjs`에서 시작하고, PNG 원본 변경은 `scripts/build-notion-sprites.mjs`에서 한다.
- 입구에서 41석까지의 접근 경로와 카운터에서 41석까지의 배달 경로를 확인했다. Chrome 로컬 1920×993에서 41석 전체 렌더링과 게시판 메뉴 진입·상태 필터 표시를 확인했다.
- 매점 주문 화면은 활성 좌석과 주문 좌석을 비교하며 메뉴 가격과 잔액을 표시한다. D1 포인트 스키마가 있을 때만 가격이 차감된다. 최근 수정분은 실제 매점 주문·재시도·좌석 변경에서 다시 확인해야 한다.
- 현재 단위 테스트는 55개 중 46개가 통과했다. 실패 9개는 배달 경로 2개, 스프라이트 및 아틀라스 2개, 이동 크기·문턱·클릭·룸 전환 4개, 휴식 중 쟁반 1개다. 구배치 상수 기대값을 새 배치로 바꾸고 실제 휴식 중 쟁반 동작도 확인한다.

## 남은 검수와 작업

- 390px 화면에서 정수 확대, 손가락 드래그/핀치/퀵버튼, 휴식 버튼 2행, UI 가림을 확인한다. 창 크기, 낮·밤, 야외 풍경, 저모션, 첫 로드 스프라이트 용량을 Notion 검수표와 대조한다.
- 게시판의 글 등록과 실제 관리자 상태 변경, A05→A10→룸 이동 시 주문/쟁반/도착 알림, 매점 잔액 부족·동시 요청 차감, PC 모달 규격을 실제로 확인한다.
- 단골 카드 3칸과 쿠폰 10칸 통합, 오목 흑 금수 규칙은 남아 있다.
- 운영 배포는 별도 검수 후 진행한다.
